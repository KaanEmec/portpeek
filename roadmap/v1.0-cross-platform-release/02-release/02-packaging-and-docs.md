# Job: publish the 1.0 release

## Objective
Deliver a small, trustworthy tool people can install and evaluate quickly.

## Tasks
- Build and check binaries for the supported macOS, Linux, and Windows targets.
- Add CI for tests, formatting, and platform builds; verify real-socket behavior on each claimed OS.
- Write installation, quick examples, JSON examples, permission notes, and a short troubleshooting section.
- Add licence, release notes, checksums, and a clear statement of supported versions/platforms.

## Expected outcome
A tagged 1.0 release has working downloads, reproducible checks, and documentation that matches tested behavior.
