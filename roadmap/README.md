# Port Peek roadmap

| Version | Outcome | Epics |
|---|---|---|
| [v0.1 — macOS answer](v0.1-macos-answer/) | One trustworthy, read-only answer for a macOS port. | CLI contract, macOS inspection, validation |
| [v0.2 — safe control and Linux](v0.2-safe-control-and-linux/) | Optional confirmed stop action and a Linux adapter. | Safe control, Linux adapter |
| [v1.0 — cross-platform release](v1.0-cross-platform-release/) | Windows support, stable JSON, and distributable releases. | Windows adapter, release |
| [v1.1 — port TUI](v1.1-port-tui/) | Searchable local-port overview with ownership, exposure, details, and refresh. | Port inventory, terminal interface, actions and release |

Within each epic, run numbered job files in order. Jobs in different epics may overlap only when their inputs are already defined. The expected outcome in each file is the completion check; version names are targets, not claims that anything has shipped.
